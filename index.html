Automatic import (iPhone Shortcuts)

An iPhone will not let any app read your text messages. Instead, a Shortcut on your iPhone saves each bank message to a file on your phone, and you load that file here. Nothing leaves your phone. Messages already imported are skipped, so loading the same file again is safe.

What the file must look like
<<<FB>>>
Received: 2026-09-28 19:06
Your card ending 1920 was used for AED 28.50 at Carrefour on 28 Sep 2026 at 19:05.
<<<FB>>>
Received: 2026-09-29 08:20
(the next bank message, exactly as received)
Each message starts with a line <<<FB>>>. The Received line is optional and is only used when the message itself has no date or time.
How to set it up on iPhone (one time)
  1. Open Shortcuts, then Automation, then +, then Message.
  2. Under Message Contains, type a phrase your bank's messages always contain, for example AED. (Banks usually send from a name that iPhone cannot pick as a Sender, so matching the text is more reliable.) Tap Next.
  3. Add the action Format Date (Current Date, custom format yyyy-MM-dd HH:mm).
  4. Add the action Text with three lines: <<<FB>>>, then Received: followed by the Formatted Date, then the Shortcut Input (the message).
  5. Add the action Append to File. Pick the file FamilyBudget-messages.txt in On My iPhone > Shortcuts and turn on "Make New File if Necessary" if you see it. Tap Done.
  6. Any time, tap Choose messages file above and pick that file. Every imported message waits in Review on Home. You check it, choose a category and save.
  7. So it runs without asking you: choose Run Immediately if iOS offers it, or open the shortcut's info (i), tap Privacy and turn on Allow Running When Locked. The first run may ask permission for the file; allow it.

On Android the same button works with any file your automation app writes in this format.

Set Up AutoLog

Set up both message workflows for Family Budget. iPhone will ask for any permissions required when you run an authorized Shortcut or automation.

1 · New bank messages

Use an iPhone Message automation to append incoming bank SMS to FamilyBudget-messages.txt. This preserves your existing new-message import workflow.

2 · Older bank messages

Run the historical export Shortcut, then select its FamilyBudget-history.txt file and preview before importing.

Why does iPhone ask me to approve this?

Apple controls access to Messages and automation permissions. A website cannot silently create or authorize iPhone Shortcuts. This screen opens the Shortcuts app and connects to the existing import flows; the actual Shortcuts must be created/installed and approved on the iPhone.

Fetch old bank messages

Use the separate iPhone Shortcut to search available message history and save it as FamilyBudget-history.txt. Then choose that file here. Family Budget will preview the transactions and skip duplicates before saving.

Step 1 · Fetch messages

Runs the Shortcut named Export bank messages. This works only after that Shortcut has been created on your iPhone and granted permission to find messages.

Step 2 · Import the export

After the Shortcut finishes, return here and select FamilyBudget-history.txt from the location where you saved it.

Important: one-time Shortcut requirement

This app cannot install an Apple Shortcut by itself or read Messages directly. The separate Export bank messages Shortcut must already exist on your iPhone. The button above launches it; it does not create it. iOS may limit which messages can be found, and the Shortcut must save the output as FamilyBudget-history.txt.
